Research

  • Memory & capacity. Investigating how network structure shapes information storage and recall, including MLP memory studies and neural memory work with UCLA’s TITANS project team.
  • Attention & context. Studying how models use context, from the effective token width of attention to controlled comparisons of attention-only and standard Transformers.
  • Compression & efficiency. Working on low-bit quantization, activation sparsity, and efficient representations, with an interest in what can be removed while preserving model behavior.
